# BUCKSHOT // DOH CIPHER MANAGER

Ретро-индустриальное десктопное приложение для Windows (в стиле **Buckshot Roulette CRT-терминала**), которое полностью автоматизирует установку, запуск и управление зашифрованным **DNS-over-HTTPS (DoH)** через утилиту [AdguardTeam/dnsproxy](https://github.com/AdguardTeam/dnsproxy).

---

## 🎯 Ключевые возможности

| Функция | Описание |
|---|---|
| 🕹 **Buckshot Roulette CRT** | Ретро-индустриальный монитор, осциллограф, эффекты линзы, шум люминофора и тумблеры |
| 🛡 **Активация в 1 клик** | Программа поднимает локальный шлюз dnsproxy v0.85.0 и безопасно переключает DNS адаптера |
| ⚡ **Актуальные профили** | Интеграция с официальным **Xbox DNS** (`https://xbox-dns.ru/dns-query`), сервисом **GeoHide DNS** (`https://geohide.ru/dns-query`, RU и US шлюзы), Cloudflare, Google DNS, AdGuard, Quad9 и кастомный DoH |
| 🚀 **Правильный Автозапуск** | Запуск через **Windows Task Scheduler** с наивысшими правами (`HighestAvailable`), без всплывающего окна UAC |
| 🛡 **Авто-активация** | Автоматическое включение шифрования при загрузке системы |
| 🩺 **Диагностический аудит** | Вкладка полной 8-этапной проверки сети, UAC, TLS DoH, пинга и сквозного резолвинга (включая ChatGPT, Xbox, Live) |
| 🧹 **Аварийный сброс (DHCP)** | Восстановление заводских настроек сетевых карт, сброс кэша и остановка зависших процессов в 1 клик |
| 📥 **Системный трей** | Работает в фоне рядом с часами, цветная индикация статуса и управление через контекстное меню |
| ↩ **Безопасное выключение** | При выходе или аварии всегда восстанавливает оригинальные сетевые параметры Windows |

## 🛠 Быстрый старт (из исходников)

### Требования
- **Windows 10 / 11 (64-bit)**
- **Python 3.10–3.14**
- Права **Администратора** при запуске (UAC-запрос выполняется автоматически)

### 1. Установка зависимостей
```bat
pip install -r requirements.txt
```

### 2. Запуск приложения
```bat
py -3.14 main.py
```
*(или дважды кликните `run.bat`)*

---

## 📦 Сборка в один EXE-файл

Для создания автономного `.exe` без необходимости устанавливать Python:

```bat
build.bat
```

Исполняемый файл будет скомпилирован в папку `dist\Buckshot-DoH.exe`.

## ⚙️ Технические детали

1. **UAC Bypass для автозапуска**: приложение регистрирует системную задачу в Windows Task Scheduler (`\BuckshotDoH_Autostart`) с флагом `HighestAvailable` и привязкой к интерактивной сессии пользователя, что избавляет от блокировок Windows при старте.
2. **Защита от переполнения пайпов**: логи `dnsproxy.exe` пишутся напрямую в файл `dnsproxy.log` без блокировок буферов Windows.
3. **Автолечение сети при сбоях**: если ПК перезагрузился или был выключен во время работы, приложение при следующем запуске обнаружит зависший адрес `127.0.0.1` и восстановит сетевой стек в исходное состояние.
